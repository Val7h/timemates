BACKEND - PYTHON
================

6. models_extensions.py (3.5 KB)
   - Modelo Event (eventos da sala)
   - Modelo EventRSVP (respostas a eventos)
   - Modelo Notification (notificações)
   - Modelo PushSubscription (subscriptions push)
   - Modelo UserPresence (presença online)
   - Modelo MessageReaction (reações em mensagens)
   - Modelo News (notícias do sistema)
   - Modelo EmailLog (log de emails)

7. notification_service.py (7.8 KB)
   - Classe NotificationService
   - Métodos de push notifications (Web Push API)
   - Métodos de email (SMTP)
   - Agendamento de reminders (24h antes)
   - Weekly digest (segunda 10am)
   - Breaking news alerts
   - Inicialização do scheduler APScheduler

8. notification_routes.py (8.5 KB)
   - Router FastAPI para notificações
   - Endpoints CRUD de notificações
   - Push subscriptions (subscribe/unsubscribe)
   - Eventos (create/list/rsvp)
   - Presença online (update/list)
   - Reações em mensagens (add/remove/list)
   - WebSocket para broadcasts em tempo real
   - ConnectionManager para gerenciar conexões

9. tracking_service.py (6.3 KB)
   - Classe TrackingService
   - Métodos para GA4 tracking
   - Eventos: click_news, rsvp_event, view_highlights, reaction_added, etc
   - Measurement Protocol do GA4
   - Suporte a user properties e custom events
   - Métodos de relatórios (read-only)
   - Script HTML para GA4
