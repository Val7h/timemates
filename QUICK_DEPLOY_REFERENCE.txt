================================================================================
TROUBLESHOOTING
================================================================================

PROBLEMA: ModuleNotFoundError: No module named 'database'
SOLUÇÃO: Executar no diretório raiz (C:\Users\Admin\timeMates\)

PROBLEMA: DATABASE_URL not set
SOLUÇÃO: Usar SQLite localmente (.env ou default timeMates.db)
         Em Render, setar DATABASE_URL na configuração de env

PROBLEMA: Seed script não executa
SOLUÇÃO: pip install -r requirements.txt
         Verificar Python 3.8+

PROBLEMA: Dados não aparecem nos endpoints
SOLUÇÃO: Confirmar que seed_deployment_data.py foi executado
         Verificar database com: sqlite3 timeMates.db ".tables"

PROBLEMA: Render build falha
SOLUÇÃO: 1. Verificar logs no Render Dashboard
         2. git push origin master (refazer push)
         3. Deletar serviço e criar novo se necessário
